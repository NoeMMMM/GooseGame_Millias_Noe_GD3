# GooseGame_Millias_Noe_GD3

Le jeu est un jeu de l'oie classique il devra être sur un plateau de 63 case.
La 63 eme est la fin de la partie 
Des cases renvoie de quelque case en arrière d'autre vers l'avant (entre 5-7 cases)
1 case (60) renvoie au tout début
Des Monstres/obstacles sont sur la map il faut faire un lancer plus haut que leur pouvoir pour passer 
(le pouvoir baisse de 1 jusqu'a la réussite (voir mii party))
Les battres donne un pouvoir (Ajoute un montant à son dé avant de lancer (entre 1-6)/ permet de donné +1 à son dé apres lancer/ Lance 2 Dés)

Faire le cache cache (voir mario Party/ Se cache derrière des obstacles un rideau tombe et les ia se cache, 
le rideau ce lève, on trouve l'ia elle est éliminé. Il faut les trouver en trois manche, les ias peuvent être caché au même endroit )
